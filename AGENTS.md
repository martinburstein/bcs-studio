# Publication repository

This repository contains public releases of The Big Crypto Short. Conduct research, experiments, source capture, drafting, numerical changes and review in the private `martinburstein/the-big-crypto-short-lab`. Do not use this public repository as the working lab.

Publish only an explicitly authorized, filtered package from a verified private checkpoint. Start from an allowlisted clean export; never mirror or merge the private repository's history. Preserve source dates, citations, counterevidence, failed or unresolved findings relevant to the conclusions, and the distinction between internal AI review and external peer review.

Exclude credentials, signed URLs, personal holdings/account material, internal worker sessions and drafts. Verify reproduction, links, file checksums and every PDF page before publication. Keep working-paper status and research limitations accurate; do not convert a conditional study into a forecast or a trade recommendation. Changes to substantive claims return to the private lab for review before a new public release.
